## 3주차

### 다중 사용자 시스템의 특징
- 여러 사람이 하나의 파일 시스템을 사용
- 다른 사람이 내 파일을 삭제,수정,읽기등을 못하게 보안 필요
- 내 파일에 접근권한을 부여해서 접근권한 만큼만 파일을 사용하게한다.

### 파일의 속성
- 유닉스에서 파일을 관리하기위해 저장하는 속성들
- ls- l 로 확인할 수 있다
- 파일 종류, 접근 권한, 하드링크수 , 소유자 id, 그룹id, 파일크기, 수정일시, 파일명

### 파일 종류
- -: 일반파일
- b: 블록파일
- d: 디렉토리파일
- c: 문자파일
- i: 심볼릭링크 파일
- p: 파이프
- s: 소켓

### file 파일명
file의 종류를 표시

### groups 사용자
사용자명 x => 자신이 속한 그룹이름 출력
사용자명 o => 사용자가 속한 그룹이름 출력

### 파일의 접근권한
- 다중 사용자 시스템에서 가장 기본적인 보안
- 파일을 읽고 쓰고 실행 할 수 있는 권한

### 유닉스의 사용자 카테고리
- 접근권한 카테고리 별로 다르게 부여한다
- 소유자: 파일을 생성한 사용자. 명령으로 바꿀 수 있다.
- 그룹: 파일에 동일한 그룹에 속한 사용자들
파일을 생성한 사용자의 기본 그룹
- 기타 사용자: 소유자와 그룹 카테고리에 속해있지않은 모든 사용자들

### 기본권한
- r,w,x 읽기 쓰기 실행
- 파일에 종류에 따라 의미가 다르다
 1. 읽기: 파일- 파일을 읽거나 복사할 수 있다
        디렉토리- ls 명령으로 디렉토리 목록을 볼 수있다.
 2. 쓰기: 파일- 파일을 삭제,수정,이동 할 수 있다.
        디렉토리- 파일을 생성,삭제 할 수 있다.
 3. 실행: 파일- 파일을 실행 할 수 있다.
        디렉토리- cd 명령을 사용할 수 있다.
        디렉토리로 이동이나 파일을 복사 할 수 있다.

### 접근권한 표기법
9자리로 각각 소유자, 그룹사용자, 기타 사용자에게 3자리씩 줌
1. r: 읽기 허가
2. w: 쓰기 허가
3. x: 실행 허가
4. -: 허가 취소

### `chmod [옵션] 모드 파일명`
1. 자신이 소유한 파일의 사용자 접근 권한을 변경한다
2. 옵션 : -R 하위 디렉토리도 접근권한변경
3. 모드: 기호모드 , 8진수 모드

### 기호 모드
1. `chmod 사용자 카테고리 연산자 권한 파일명`
2. 사용자 카테고리: u 소유자 g 그룹사용자 o 기타사용자 a 모든 사용자
3. 연산자: + 허가 부여, - 허가 삭제, = 허가 지정
4. 권한: r,w,x

### 숫자 모드
- `chmod 소유자 8진수 그룹 8진수 기타 8진수 파일명`
1. 숫자를 이용하여 접근권한을 표시
2. 모든 카테고리의 접근권한을 한번에 바꿀 때 기호모드 보다 편리하다
3. 3개의 8진수로 표현
4. 권한이 있으면 1 없으면 0

### 기본 접근권한
- 유닉스에서 파일이나 디렉토리를 생성할 때 부여되는 접근 권한
- 777: 실행 권한이 있는 파일
- 666: 실행 할 수 없는 파일
- 777: 디렉토리

### `umask [마스크값]`
- 기본 접근권한을 출력하거나 변경
- 파일이나 디렉토리를 생성할 때 권한을 부여하고 싶지 않은 권한 지정
- 마스크 값 지정 -> 마스크값이 지정
- 마스크 값 x -> 현재 설정된 마스크값을 출력


### mask
1. 가리다
2. 사용 권한에 부여하지 않을 권한 지정
3. XOR 마스크를 이용한 접근 권한 생성

### 대표적인 MASK
1. 022: 그룹, 기타 사용자의 쓰기 권한제거
2. 077: 그룹, 기타 사용자의 전체 권한제거
3. 027: 그룹은 쓰기, 기타 사용자의 전체권한 제거

## 절대경로 상대경로
- 경로: 파일 시스템에서 현재 파일의 위치
- 절대경로: 루트 디렉토리 기준부터 시작, 루트부터 특정 파일까지 가는데 거치는 모든 디렉토리의 이름을 표시, /부터 시작한다
- 상대경로: 현재 디렉토리 기준부터 시작, /로 시작 안하고, 현재 디렉토리부터 특정 파일까지 가는데 거치는 모든 디렉토리 이름을 표시, 같은 파일 상대 경로라도 현재 디렉토리에 따라 달라짐
- /home/user1/Unix
- Unix
- /home/user2
- ../user2

## `pwd`
- 현재 작업 디렉토리의 절대 경로를 출력

## `cd [디렉토리 명]`
- 현재 작업 디렉토리를 지정한 디렉토리로 이동
- 디렉토리명 지정 안 하면 홈 디렉토리로 이동

## `ls [옵션] [file or directory]`
- 파일이나 디렉토리 정보를 출력

## `mkdir [옵션] [디렉토리명]`
- 새로운 디렉토리를 생성
- 옵션 -p: 새로운 디렉토리를 생성할때 필요한 하위 디렉토리도 같이 생성

## `rmdir [옵션] [디렉토리명]`
- 지정한 디렉토리를 삭제
- 옵션 -p: 지정한 디렉토리를 삭제하고 부모 디렉토리가 비어있으면 삭제
- 디렉토리가 비어있어야 삭제가능
