# TIL

## 브랜치 정의
- 브랜치는 어떤 '특정한 목표'를 가지고 코드를 수정하기 시작할 때 만든다. (기능추가, 버그 수정)

- 뭔가 일을 할때는 첫번째 이슈를 생성한다 (이슈 트랙커)

- 두번째 이슈에 맞는 브랜치를 생성한다. (git branch 브랜치 이름) 

   - ex) git branch 1-dfdfdf

- 세번째 생성한 브랜치로 전환해서 작업한다. (git checkout 1-dfdfdf, git swtich 1-dfdfdf)

브랜치 1로 다시 커밋

## 브랜치 합치기
- 이슈에 해당하는 작업을 수행할 때, 별도의 브랜치를 만들고 작업한다.
- 작업이 끝난 후에는, 풀리퀘스트를 사용해 내가 작업한 브랜치를 중요 브랜치(`main`,`master`, `development`,`devel`)로 병합 시켜야한다.

### 명령어
- `git merge`
- 주의할점: `A`브랜치를 `B`브랜치로 합치려고 할 때는 `B`브랜치를 체크아웃 한 상에서 `git merge A`를 입력한다.
