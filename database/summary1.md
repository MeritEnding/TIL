# 데이터 베이스 2주차
## 데이터 베이스 개요
1. DBMS는 데이터베이스를 관리해주는 저장소

2. 외부스키마, 개념스키마, 내부스키마가 있다

3. 외부스키마는 고객들의 입맛대로 원하는 속성들만 뽑아내서 요구하는 특징이 있다

4. 개념스키마는 데이터베이스가 어떤것들로 구성되어있는지 나타냄( 조직 전체 관점 )

5. 내부스키마는 물리적으로 어떻게 구성되어있는지를 나타냄

## 데이터 언어: DML, DDL, DCL

1. `DML`:데이터 조작어로 데이터의 삽입, 삭제, 수정 , 검색 등의 처리를 요구하기 위해 사용됨


2. `DDL` : 데이터 정의어로 스키마를 정의하거나 수정, 삭제 할때 사용됨

3. `DCL` : 데이터 제어어로 내부적으로 필요한 규칙 정의하기 위해 사용됨
